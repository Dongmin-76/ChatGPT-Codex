# 처음부터 따라 하는 설치·사용 안내

이 프로그램은 본인 컴퓨터에서 웹서버를 실행하고 브라우저로 사용하는 방식입니다. 다른 사람이 운영하던 서버나 API 키에 의존하지 않습니다.

## 1. 준비물

- 인터넷에 연결된 Windows 10/11 컴퓨터. macOS·Linux는 아래의 터미널 방법을 이용합니다.
- Chrome 또는 Edge 등 최신 브라우저.
- [Node.js 24 LTS](https://nodejs.org/en/download). Windows는 일반적으로 x64 Installer를 선택하고 기본 설정으로 설치합니다.
- 본인 명의의 OpenAI API 키 및 해당 프로젝트의 API 이용 가능 상태.
- 인포그래픽으로 바꿀 PDF 업무계획서. 최대 30MB, 120쪽, 암호화되지 않은 파일.

Node.js는 이 앱을 실행하는 프로그램입니다. Python, 별도 데이터베이스, Git, Codex를 설치할 필요는 없습니다. PDF 분석 및 이미지 생성은 온라인 OpenAI API를 사용하므로 인터넷 연결은 필요합니다.

## 2. 코드 다운로드와 압축 풀기

1. [GitHub 저장소](https://github.com/Dongmin-76/ChatGPT-Codex)를 엽니다.
2. 초록색 **Code** 버튼을 누르고 **Download ZIP**을 선택합니다.
3. 내려받은 ZIP을 마우스 오른쪽 버튼으로 클릭하고 **압축 풀기 / 모두 추출**을 선택합니다.
4. 압축을 푼 폴더를 엽니다. `README.md`, `package.json`, `1-install.cmd`가 같은 위치에 보여야 합니다.

ZIP 안에서 파일을 직접 실행하지 마세요. 클라우드 동기화 폴더보다는 `C:\PolicyCanvas` 같은 일반 폴더를 사용하면 경로·권한 문제를 줄일 수 있습니다.

## 3. 필요한 프로그램 설치 — 처음 한 번

`1-install.cmd`를 더블클릭합니다. 검은 창에 설치 진행 상황이 표시됩니다. 첫 설치는 네트워크에 따라 몇 분 걸릴 수 있습니다.

**설치 완료**라는 메시지가 나오면 끝입니다. 설치 완료 메시지가 없다면 아래 문제 해결 표를 확인하세요. 설치 과정에서 관리자 권한이나 API 키 입력은 요구하지 않습니다.

이 과정은 필요한 라이브러리를 설치하고, 키가 비어 있는 `.env.local` 파일을 만듭니다. 이미 설정한 `.env.local`은 덮어쓰지 않습니다.

## 4. 본인의 API 키 설정

1. [OpenAI Platform API 키 관리](https://platform.openai.com/api-keys)에서 본인 프로젝트의 키를 준비합니다. 처음 사용하는 계정은 API 결제·이용 한도와 모델 권한도 확인합니다.
2. `2-api-key.cmd`를 더블클릭합니다.
3. 메모장에 열린 파일에서 `OPENAI_API_KEY=` 줄을 찾습니다.
4. **등호 바로 뒤에** 발급받은 키를 붙여넣습니다. 줄을 나누거나 `OPENAI_API_KEY`라는 이름을 바꾸지 않습니다.
5. **Ctrl+S**로 저장한 뒤 메모장을 닫습니다.

파일 이름은 정확히 `.env.local`이어야 합니다. `.env.local.txt`로 저장하면 읽지 못합니다. 위 설정 파일을 사용하면 직접 이름을 붙일 필요가 없습니다.

실제 키를 README, `.env.example`, GitHub, 채팅, 화면 캡처에 넣지 마세요. 프로그램의 진단 명령은 키가 설정됐는지만 보여주고 값을 출력하지 않습니다.

키가 없더라도 화면을 열어 디자인을 확인할 수 있습니다. 다만 **인포그래픽 만들기**는 활성화되지 않습니다. 키를 설정했다면 실행 중인 프로그램을 종료하고 다시 시작하세요.

## 5. 프로그램 실행

1. `3-start.cmd`를 더블클릭합니다.
2. 잠시 뒤 브라우저가 열립니다. 자동으로 열리지 않으면 주소창에 **http://127.0.0.1:5173**을 입력합니다.
3. 화면 아래에 **OpenAI API 연결됨**이 표시되는지 확인합니다. 이는 서버에 키가 설정돼 있다는 뜻이며, 키의 유효성·크레딧·모델 권한은 실제 요청 시 확인됩니다.
4. 사용하는 동안 실행 창을 닫지 않습니다.

이 주소는 본인 컴퓨터에서만 열리는 주소입니다. 지인에게 주소를 보내도 그 사람의 컴퓨터에서는 접속되지 않습니다.

## 6. 인포그래픽 만들기

1. **업무계획서 업로드** 영역을 클릭하고 PDF를 선택합니다.
2. 표시된 파일 이름과 전체 페이지 수가 맞는지 확인합니다.
3. 세 가지 스타일 중 하나를 고릅니다. 고품질은 더 많은 시간이 들 수 있습니다.
4. 필요하면 **추가 요청**에 디자인 강조점을 적습니다. **기획안 먼저 검토하기**를 선택하면 이미지 생성 전에 내용을 확인할 수 있습니다.
5. **인포그래픽 만들기**를 누릅니다.
6. 전체 페이지 분석 → 전체 내용 종합 → 이미지 생성 순서로 진행됩니다. 긴 문서는 몇 분 이상 걸릴 수 있으므로 탭과 실행 창을 열어둡니다.
7. 기획안 검토를 선택했다면 근거 내용을 확인한 뒤 **기획안으로 이미지 생성**을 누릅니다.
8. 완료되면 **PNG 다운로드** 또는 **PDF** 버튼으로 저장합니다. 결과 파일은 일반적으로 브라우저의 다운로드 폴더에 저장됩니다.

**분석 근거 저장**을 누르면 페이지별 분석과 기획안을 JSON 파일로 저장할 수 있습니다. 현재 버전에는 이 파일을 다시 불러와 작업을 재개하는 기능은 없습니다.

새로고침하거나 창을 닫으면 현재 작업은 사라집니다. 결과를 먼저 저장하세요. 작업 중단 버튼을 누르더라도 이미 진행된 API 요청의 비용은 취소되지 않을 수 있습니다.

## 7. 종료와 다음 실행

- 실행 창을 클릭하고 **Ctrl+C**를 누릅니다. 종료 확인이 나오면 안내에 따릅니다.
- 다음에는 `3-start.cmd`만 실행하면 됩니다.
- 키를 바꾸거나 지웠다면 프로그램을 다시 시작해야 설정이 반영됩니다.
- 새 버전을 내려받을 때는 새 폴더에 압축을 풀고, 설치 후 본인의 키를 다시 설정하세요. 기존 결과 파일은 별도로 보관합니다.

## 문제 해결

| 증상 | 해결 방법 |
| --- | --- |
| `node`를 찾을 수 없다고 나옴 | Node.js 24 LTS를 설치합니다. 설치 뒤 기존 창을 닫고 다시 실행합니다. |
| 설치 도중 네트워크 오류 | 인터넷·회사 프록시를 확인한 뒤 `1-install.cmd`를 다시 실행합니다. |
| `npm.ps1` 실행 정책 오류 | `.cmd` 파일을 사용하거나 터미널에서 `npm.cmd`로 실행합니다. 보안 정책을 끌 필요는 없습니다. |
| 브라우저가 열리지 않음 | 실행 창에 Local 주소가 나오는지 확인하고 `http://127.0.0.1:5173`을 직접 엽니다. |
| 5173 포트가 사용 중 | 이전에 실행한 창에서 Ctrl+C로 종료합니다. 다른 프로그램이 쓰는 경우 `npm run dev -- --port 5174`로 실행하고 출력된 주소를 사용합니다. |
| API 키 연결 필요 | `2-api-key.cmd`로 키를 저장했는지 확인하고 프로그램을 다시 시작합니다. `.env.local.txt`는 잘못된 파일 이름입니다. |
| 키가 만료됐거나 유효하지 않음 | 본인의 유효한 키로 바꾸고 다시 시작합니다. 키 값을 다른 사람에게 보내지 마세요. |
| API 한도·크레딧 부족 | OpenAI Platform의 결제 및 사용 한도를 확인합니다. ChatGPT 구독만으로 API 비용이 결제되지는 않습니다. |
| 모델 권한 없음 | 키를 발급한 프로젝트가 기본 분석·이미지 모델을 사용할 수 있는지 확인합니다. 모델 이름과 지원 규격은 README의 개발자 안내를 참고합니다. |
| 일부 페이지 판독 불가 | 해당 페이지를 선명하게 스캔하거나 암호를 해제한 PDF로 다시 저장합니다. |
| 분석·기획안 오류 | 현재 탭에서 다시 시도합니다. 완료된 분석을 재사용합니다. 계속 실패하면 화면의 실패 단계와 오류 번호를 기록합니다. |
| 결과 한글·숫자가 이상함 | 화면의 분석 근거와 원문을 대조합니다. 기획안을 확인하고 새 이미지를 생성합니다. AI 이미지의 글자는 검수가 필요합니다. |

## macOS·Linux

Node.js 24 LTS를 설치합니다. 압축을 푼 폴더를 터미널로 열고 실행합니다.

```sh
npm run setup
npm run configure
```

출력된 `.env.local` 경로를 텍스트 편집기로 열어 본인의 키를 설정하고 저장합니다. 이후:

```sh
npm start
```

화면 확인은 `http://127.0.0.1:5173`, 종료는 Ctrl+C입니다. macOS·Linux용 절차도 제공하지만 이번 배포의 실제 설치·실행 검증은 Windows와 Node.js 24에서 진행했습니다.
